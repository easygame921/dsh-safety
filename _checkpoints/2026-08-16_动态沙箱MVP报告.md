| 验收项 | 结果 | 证据 |

## 3. 安全边界验证（docs/DYNAMIC-SANDBOX.md §8 复查）

- [x] 无真实网络连接：fetch patch 拒绝 + permission model 禁网；轨迹仅记录 URL/主机
- [x] 无真实命令执行：permission model 拒绝 child_process
- [x] 无真实文件读写：HOME/USERPROFILE 重定向到沙箱临时目录；读 ENOENT 被隔离（exfil 实证）
- [x] 无真实 eval：eval/Function patch 记录不执行
- [x] 超时必杀：20010ms 实证

## 4. 技术要点与已知限制（诚实记录）

1. **ESM 的 fs/child_process 无法插桩**（import 绑定原生模块）——轨迹中 fs-read/command 主要靠
   **错误即证据**（ENOENT 路径、permission 拒绝）提取，行为触发但记录粒度受限。
2. **ctx mock 覆盖有限**：真实样本暴露并补齐了 `ctx.effect`、`ctx.tool().register()` 等表面；
   仍有未知表面会报错（记录为 errors，不影响安全边界）。
3. **事件触发有限**：仅 session/start、agent/turn/start、session/end；工具调用不模拟。
4. **依赖重的插件 load-failed**：npm tarball 无 node_modules，外部依赖无法加载。
5. **异步行为窗口 800ms**：超长延迟的恶意行为可能漏（但沙箱不真执行危险动作，漏的是"轨迹"）。
