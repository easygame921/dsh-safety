# ADR-002 自动触发机制：agent 指令层而非插件监听

## Context
用户希望"提及安装 dsh 插件时自动触发 dsh-safety 审计并输出报告"。MCP 服务器是被动
工具（stdio），无法监听 DSH 会话事件或 `dsh plugin add`。候选方案：A) 改 MCP 为常驻
监听进程（侵入 DSH 内部事件，破坏信任隔离）；B) 写一个 dsh 插件 hook 插件安装事件
（插件本身运行在信任域内，存在自举问题）；C) agent 指令层引导（AGENTS.md 约定）。

## Decision
采用 C：把「先审计后安装 + 对话流摘要 + 按需文件报告」写进全局 agent 指令
（~/.dsh/AGENTS.md），由会话 agent 自觉执行；MCP 保持被动、独立进程。

## Consequences
- 正面：零侵入、信任隔离保持；实现成本最低；可随 AGENTS.md 分发/更新。
- 负面：依赖 agent 自觉（软约束）；不同 agent 模型执行一致性有波动；用户绕过 agent
  直接 `dsh plugin add` 时不触发（后续如需硬闸门，再评估 DSH CLI hook 支持）。
